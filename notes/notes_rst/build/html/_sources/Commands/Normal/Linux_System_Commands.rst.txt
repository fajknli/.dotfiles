Linux系统命令
###############

1. linux 查看存储空间
======================

1. linux磁盘/挂载的文件系统使用量
-----------------------------------------------------

::

    df -h

2. 检查文件和目录的磁盘使用量
-----------------------------------------------------

::

    du -sh *

3. 列出块设备以及其挂载点
-----------------------------------------------------

::

    lsblk

4. 监视系统输入/输出设备负担
-----------------------------------------------------

::

    iostat

5. 一次性创建多个嵌套文件夹
-------------------------------

::

    mkdir -p ~/some/nested/directory/structure

2. linux查看系统信息
=======================

1. uname查看系统信息

2. lscpu查看cpu信息

3. lspci列出所有pci设备

4. lsusb列出所有usb设备

3. 文件权限所有权
=====================

1. chmod改变文件权限

2. chown 改变文件所有者

3. chgrp 改变文件所属组
