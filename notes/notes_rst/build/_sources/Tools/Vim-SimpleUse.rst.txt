Vim SimpleUse
##############

移动
======

1. ctrl + f     向前(下)一页
2. ctrl + b     向后(上)一页
3. H            将光标置于屏幕顶部(High)
4. M            将光标置于屏幕中部(Middle)
5. L            将光标置于屏幕底部(Low)
6. gg           将光标置于文件开头
7. G            将光标置于文件末尾
8. H            将光标置于行首
9. L            将光标置于行尾
10. Ctrl + o    如果不小心按到G,可以这样返回上一个地方(是字母o,不是0)
11. Ctrl + i    如果你用 Ctrl + O 回退太多，可以用 Ctrl + I（或 Tab键）向前跳转
12. ''          直接跳回最后一次跳转前的位置（比 Ctrl + O 更精准）（两个单引号）

注意: Ctrl + o/i 会进行全局文件位置的跳转，会进入到不同文件里

命令行光标移动
--------------------

============   ===============  ===========     ====================
功能           传统Vim键位      现代化键位      说明
============   ===============  ===========     ====================
行首           CTRL-B / Home    CTRL-A          更符合终端习惯
行尾           CTRL-E / End     CTRL-E          保持一致
左移字符       Left	            CTRL-B          Emacs风格
右移字符       Right            CTRL-F          Emacs风格
左移单词       CTRL-Left        ALT-B           终端友好
右移单词       CTRL-Right       ALT-F           终端友好
删除左侧字符   Backspace        CTRL-H          与SSH会话兼容
删除右侧字符   Del              CTRL-D          直观易记
删除左侧单词   CTRL-W           CTRL-W          保持不变
删除右侧单词   \-               ALT-D           新增功能
============   ===============  ===========     ====================

窗口
=====================

1. <leader>hh   水平打开窗口
1. <leader>vv   垂直打开窗口



窗口导航(移动光标，不是移动窗口)
------------------------------------

1. <C-h>        移动到左边窗口
2. <C-j>        移动到下边窗口
3. <C-k>        移动到上边窗口
4. <C-l>        移动到右边窗口

移动窗口
-------------------------

1. <leader>wh   将当前窗口移动到左边
2. <leader>wj   将当前窗口移动到下边
3. <leader>wk   将当前窗口移动到上边
4. <leader>wl   将当前窗口移动到右边

最大/小化窗口
------------------

1. <leader>w-   最小化窗口
2. <leader>w=   最大化窗口

In/Decrease Number
=====================

1. Ctrl + a     Increase a Number

2. Ctrl + x     Decrease a Number

Change the case
====================

1. gU   Change to Uppercase

2. gu   Change to Lowercase

TABs
=========

<leader> = \

1. <leader> + t + n     创建一个新标签
2. <leader> + t + o     只留下这一个标签，其他都删除
3. <leader> + t + c     关闭这个标签
4. <leader> + t + m     移动标签
5. <leader> + t + l     移动到右边(下一个)标签     
6. <leader> + t + h     移动到左边(上一个)标签
7. <leader> + t + e     将目标文件以新的Tab打开

Buffers
===============

1. <leader> + b     创建一个buffer(缓冲区)
2. <leader> + b + n     切换到下一个buffer缓冲区
3. <leader> + b + d     删除当前这个buffer缓冲区

fzf模糊搜索
============

1. <leader> + f     打开当前目录下的模糊搜索
2. <leader> + c + d 进入当前文件所在的目录(配合模糊搜索使用，可以编辑目标文件目录里其他文件)

标签
======

1. m<字符>      标记(mark)一个地方,以这个<字符>作为标记符,重新设置可覆盖
2. '<字符>      回到<字符>这个标记点

高亮搜索
============

1. *            向前搜索，按N往前搜索
2. #            向后搜索，按N往后搜索
3. <leader>sc   取消高亮字符

自定义
============

1. <leader>cu   复制当前行存在的超链接

Other
========

1. ==           调整此行缩进
2. gg=G         调整全文缩进
