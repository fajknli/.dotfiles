Keybinding
=======================================================

1.Window Options
-------------------------------------------------------

Mod+W       切换Tab模式或column纵向排列

Mod+I       将后面的column放前面column下面(没开Tab模式就是纵向排列)

Mod+U       将下面的column从下往上按顺序释放

Mod+O       全局column视图

Mod+Q/H     切换到前一个窗口

Mod+E/L     切换到后一个窗口

Mod+J       切换到下窗口(一般在Mod+I后)

Mod+K       切换到上窗口(一般在Mod+I后)

Mod+Shift+Q 关闭当前窗口

Mod+Shift+L 右移一个窗口

Mod+Shift+H 左移一个窗口

Mod+Shift+J 将窗口移动到下一个工作区

Mod+Shift+K 将窗口移动到上一个工作区

Mod+Alt+H   移动到工作区第一个窗口

Mod+Alt+L   移动到工作区最后一个窗口

Mod+F       最大化当前窗口

Mod+Shift+F 全屏当前窗口

Mod+C       屏幕居中当前窗口

Mod+Ctrl+H  向右缩减10%的窗口比例

Mod+Ctrl+L  向右增加10%的窗口比例

Mod+Ctrl+J  向下增加10%的窗口比例

Mod+Ctrl+K  向上缩减10%的窗口比例

Mod+Alt+O   设置当前窗口的高度预设值

Mod+Alt+P   设置当前窗口的宽度预设值

Mod+V       浮动当前窗口

Mod+Shift+V 切换固定窗口和浮动窗口的选择

2. Workspace Navigation
-------------------------------------------------------

Mod+{number}            切换窗口到指定编号窗口
Mod+Shift+{number}      移动窗口到指定编号窗口

3. Screenshots
-------------------------------------------------------

Ctrl+Alt+Shift+P        区域截图

Ctrl+Alt+Shift+S        全屏截图

Ctrl+Alt+S              窗口截图

4. Application Launchers
-------------------------------------------------------

Mod+Return              启动终端(foot?)

Mod+Shift+Return        启动居中浮动终端窗口

Mod+D                   启动wmenu

Mod+Shift+Crtl+L        使用swaylock锁屏

Shift+Return            Minecraft游戏里输入中文

5. Audio Controls
-------------------------------------------------------

Ctrl+Alt+0              增大2%音量

Ctrl+Alt+9              减小2%音量

Ctrl+Alt+8              静音

6. Brightness Controls
-------------------------------------------------------

Ctrl+Alt+Shift+0        增加1%亮度

Ctrl+Alt+Shift+9        减小1%亮度


Mod+Shift+Slash         显示niri快捷键
