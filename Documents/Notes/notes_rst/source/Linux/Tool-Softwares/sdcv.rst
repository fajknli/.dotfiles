sdcv - StarDict CLI tool
###########################

1. how to use it 

you need download the dictionary first

https://web.archive.org/web/20230717122310/http://download.huzheng.org/

2. then put the ``.dict`` file into ``$XDG_DATA_HOME/stardic/dic``

3. start ``sdcv`` command, and you can check the dictionary now. good luck
