Commands List¶

1. 文件和数据管理¶

文件操作与复制：¶

  • cd: 更改当前工作目录。

  • df: 显示文件系统的磁盘空间使用情况。

  • dirs: 显示当前工作目录的栈，通常用于显示你之前访问过的目录。

  • du: 估算文件或目录的磁盘使用空间。

  • pwd: 显示当前工作目录的路径。

  • ls: 列出目录内容或文件的详细信息。

  • cat: 连接文件并打印到标准输出。

  • cp: 复制文件或目录。

  • ln: 创建链接，包括硬链接和符号链接。

  • mv: 移动或重命名文件或目录。

  • rm: 删除文件或目录。

  • touch: 更新文件时间戳。

目录操作：¶

  • mkdir: 创建新目录。

  • mcd: 进入指定目录并执行命令。

  • mdeltree: 删除目录及其所有子目录。

  • mlabel: 更改目录的卷标。

  • mmd: 创建多个目录。

  • mrd: 删除多个目录。

  • rmdir: 删除空目录。

文本处理：¶

  • col 用于过滤反向的行，将反向的文本转换为正向。

  • colrm 删除文本中的特定列。

  • comm 比较两个已排序文件的行，并显示它们的共同点和不同点。

  • csplit 按模式分割文件，将一个大文件分割成多个小文件。

  • ed 是一个简单的文本编辑器。 egrep: 是grep命令的扩展，支持正则表达式搜索，常用于更复杂的搜索模式。

  • fgrep 固定字符串搜索，比grep更快，因为它不使用正则表达式。

  • fmt 重新格式化段落的宽度，使其更美观。

  • fold 将每行文本折行到指定的宽度。

  • grep 搜索文件中的行，这些行与指定的模式相匹配。

  • ispell 是一个拼写检查器。

  • jed 是一个文本编辑器，类似于ed。

  • joe 是一个全屏幕文本编辑器。

  • join 将两个文件中具有相同字段的行连接起来。

  • look 在文件中搜索特定单词的行。

  • mtype 显示文件的字符编码。

  • pico 是一个简单易用的文本编辑器。

  • rgrep grep的递归版本，用于搜索目录树中的文件。

  • sed 流编辑器，用于对文本进行过滤和转换。

  • sort 对文本文件中的行进行排序。

  • spell 拼写检查器。

  • tr 转换或删除字符。

  • expr 用于执行表达式求值。

  • uniq 从已排序的文件中删除重复的行。

文件权限与属性：¶

  • chattr: 更改文件属性。

  • chgrp: 更改文件的组。

  • chmod: 更改文件的模式（权限）。

  • chown: 更改文件的所有者。

  • lsattr: 列出文件的属性。

  • mattrib: mtools中的命令，用于更改MS-DOS文件属性。

文件传输相关命令：¶

  • bye: 通常用作聊天程序或某些通信程序的退出命令。

  • ftp: 是一个用于在网络上进行文件传输的命令行程序，使用FTP协议。

  • uuto: 是uucp（Unix-to-Unix Copy）的一部分，用于在Unix系统之间传输文件。

  • uupick: 与uuto相对应，用于接收通过uucp传输的文件。

  • uucp: Unix-to-Unix Copy，用于在Unix系统之间复制文件和命令。

  • uucico: 是uucp的一部分，是通信子系统，负责数据传输。

  • tftp: 是一个简单的文件传输协议，通常用于小文件的传输，如启动文件或配置文件。

  • ncftp: 是一个改进的ftp命令，提供更多的功能和更好的用户界面。

文件系统管理：¶

  • locate: 快速搜索文件系统中的文件。

  • slocate: 安全版本的locate。

  • tmpwatch: 监视临时文件并删除旧的临时文件。

网络文件传输：¶

  • rcp: 远程复制文件。

  • scp: 使用SSH进行安全的远程文件复制。

系统信息查询：¶

  • which: 查找命令的完整路径。

  • whereis: 查找二进制文件、源代码和手册页的位置。

文件比较与合并：¶

  • cmp: 比较两个文件是否在内容上完全一致。

特殊用途：¶

  • cksum: 计算文件的CRC校验码。

  • mtools: 用于读取和写入MS-DOS格式磁盘的工具集。

  • mtoolstest: 测试mtools命令。

  • mktemp: 创建临时文件。

  • mcopy: mtools中的命令，用于复制文件。

  • mshowfat: mtools中的命令，用于显示FAT列表。

  • rhmask: 可能是设置或显示文件权限掩码的命令。

压缩与解压缩：¶

  • ar: 创建、修改、提取和查看Unix归档库文件。

  • bunzip2: 解压缩.bz2格式的文件。

  • bzip2: 使用bzip2算法压缩文件。

  • bzip2recover: 尝试从损坏的bzip2文件中恢复数据。

  • compress: 使用LZW算法压缩文件，生成.Z格式的压缩文件。

  • gunzip: 解压缩.gz格式的文件。

  • gzip: 使用gzip算法压缩文件。

  • lha: LZH压缩工具，用于压缩和解压缩.lzh和.lha文件。

  • uncompress: 解压缩.Z格式的文件。

  • unarj: 解压缩.arj格式的文件。

  • unzip: 解压缩.zip文件。

  • zip: 压缩文件并创建.zip归档。

  • zipinfo: 显示.zip文件的信息。

文件打包：¶

  • cpio: 创建或提取归档文件，通常用于备份。

文件传输与编码：¶

  • uuencode: 将文件编码为可打印字符，便于电子邮件传输。

  • uudecode: 解码由uuencode编码的文件。

  • gzexe: 压缩一个可执行文件，同时保持其可执行。

数据备份与恢复：¶

  • dump: 用于备份文件系统。

  • restore: 从备份中恢复文件系统。

  • tar: 打包和压缩文件，可以创建.tar、.tar.gz、.tgz等格式的文件。

2. 系统管理与维护¶

日期和时间：¶

  • date: 显示或设置系统的日期和时间。

  • sleep: 暂停执行一段时间。

系统状态与维护：¶

  • exit: 退出当前的shell会话。

  • halt: 安全地关闭系统。

  • login: 登录系统。

  • logout: 注销当前用户。

  • reboot: 重启系统。

  • shutdown: 关闭系统或改变系统的运行级别。

  • suspend: 暂停当前用户的活动，将控制权交还给系统。

进程管理：¶

  • kill: 发送信号给指定的进程。

  • last: 显示用户的登录历史。

  • lastb: 显示失败的登录尝试历史。

  • ps: 显示当前系统中的进程状态。

  • nice: 以指定的优先级启动一个程序。

  • renice: 更改一个或多个进程的优先级。

  • pstree: 以树状图的形式显示进程。

  • top: 实时显示系统中进程的动态。

  • w: 显示当前登录的用户和他们正在做的事情。

  • who: 显示当前登录的用户。

  • whoami: 显示当前用户的用户名。

系统监控与性能：¶

  • free: 显示系统中可用和已使用的内存。

  • tload: 显示系统负载。

  • uptime: 显示系统运行的时间和当前的负载。

安全与权限：¶

  • su: 切换到另一个用户账户。

  • sudo: 以另一个用户（通常是root）的权限来执行命令。

系统管理与配置：¶

  • reset: 重置终端，清除屏幕。

  • clear: 清除终端屏幕。

  • alias: 创建命令别名，简化常用命令的输入。

  • dircolors: 设置ls命令显示文件和目录时的颜色。

  • chroot: 更改当前进程的根目录。

  • crontab: 管理定时任务。

  • declare: 在shell中声明或修改变量。

  • depmod: 处理内核模块依赖关系。

  • dmesg: 显示内核消息。

  • enable: 启用或禁用shell的命令或别名。

  • eval: 执行一个字符串作为shell命令。

  • export: 将变量导出为环境变量。

  • grpconv: 转换组文件。

  • hwclock: 管理硬件时钟。

  • insmod: 安装内核模块。

  • kbdconfig: 设置键盘。

  • lilo: Linux引导加载器。

  • liloconfig: 配置lilo。

  • lsmod: 列出加载的模块。

  • minfo: 显示内存信息。

  • modprobe: 自动处理模块的加载和卸载。

  • modinfo: 显示模块的信息。

  • mouseconfig: 配置鼠标。

  • ntsysv: 配置系统服务。

  • passwd: 更改用户密码。

  • pwconv: 转换密码文件。

  • pwunconv: 转换密码文件。

  • rdate: 从指定的服务器获取日期和时间。

  • rmmod: 移除内核模块。

  • setup: 系统配置工具。

  • sndconfig: 配置声卡。

  • timeconfig: 配置系统时间。

  • ulimit: 设置shell的资源限制。

  • unset: 删除或禁用变量或别名。

  • chkconfig: 检查、设置系统服务的启动状态。

用户和组管理：¶

  • gpasswd: 修改组的密码或其它属性。

  • finger: 显示用户信息。

  • logname: 显示当前用户的用户名。

  • newgrp: 切换到一个新的用户组。

  • id: 显示当前用户的用户ID和组ID。

  • write: 向另一个用户发送消息。

  • chsh: 更改用户的登录shell。

用户账户管理：¶

  • adduser: 添加新的用户账户。

  • chfn: 更改用户的个人信息，如全名、办公室电话等。

  • useradd: 创建一个新的用户账户。

  • userconf: 用户配置工具，可能与adduser类似。

  • userdel: 删除一个用户账户。

  • usermod: 修改用户的账户信息。

  • groupadd: 创建一个新的用户组。

  • groupdel: 删除一个用户组。

  • groupmod: 修改用户组的信息。

创建用户并设置家目录(直接创建用户不会设置家目录,后期创建一个还要chmod 755 / chown,麻烦)

sudo useradd -m newuser newuser

添加用户到用户组 / sudo 组

sudo usermod -aG groupname newuser

sudo 组:

编辑/etc/sudoers,添加如下行:
newuser ALL=(ALL:ALL)ALL

递归改当前目录下的文件所有者:

sudo chown -R username:username .

递归改当前目录下的文件可读/写/执行权限

sudo chmod -R 755 .

复制文件时更改所有者

rsync -av --owner source_file/dir destination_file/dir

系统引导与硬件：¶

  • mkkickstart: 创建自动安装脚本。

  • fbset: 设置帧缓冲设备。

系统时间：¶

  • hwclock: 管理硬件时钟。

系统性能与监控：¶

  • apmd: 高级电源管理守护进程。

系统服务管理：¶

  • ntsysv: 用于配置系统服务。

环境变量与shell：¶

  • set: 设置或修改shell的选项。

  • setenv: 设置环境变量。

  • unalias: 删除别名。

显示与图形界面：¶

  • SVGATextMode: 设置SVGA显示模式。

键盘布局配置：¶

  • loadkeys: 加载键盘字符映射表，允许用户更改键盘布局。

  • dumpkeys: 显示当前键盘映射或键盘扫描码和功能键的绑定。

  • loadkeys和dumpkeys通常用于自定义或查看键盘的键位映射，这在多语言环境中非常有用，或者当用户需要特殊的键盘布局时。

硬件设备管理：¶

  • setleds: 设置键盘LED的状态，如Caps Lock、Num Lock等。

  • MAKEDEV: 在某些Unix系统中，用于创建设备文件，这些文件允许用户访问硬件设备。

  • rdev: 用于重新初始化或设置终端设备。

链接与符号链接：¶

  • lndir: 创建一个目录的符号链接，该目录包含指向另一个目录中文件的符号链接。

3. 存储设备管理¶

磁盘检测与分区：¶

  • badblocks: 检查磁盘上的坏块。

  • cfdisk: 是一个磁盘分区表编辑器，提供图形界面。

  • dd: 是一个用于转换和复制文件，以及创建磁盘镜像的工具。

  • e2fsck: 是一个用于检查和修复ext2/ext3/ext4文件系统的命令。

  • fdisk: 是一个磁盘分区表操作工具。

  • losetup: 用于设置和控制循环设备。

磁盘配额管理：¶

  • quota: 显示用户的磁盘配额和使用情况。

  • quotacheck: 更新配额数据库。

  • quotaoff: 关闭磁盘配额。

  • repquota: 报告所有用户的磁盘配额和使用情况。

  • quotaon: 启用磁盘配额。

CD/DVD 操作：¶

  • eject: 弹出CD/DVD驱动器。

磁盘空间分析：¶

  • edquota: 编辑用户磁盘配额设置。

  • mdu: 多目录磁盘使用情况分析，可以递归地显示多个目录的磁盘使用情况。

文件系统与磁盘：¶

  • fwhios: 可能是一个显示或操作文件系统信息的命令。

文件系统挂载与卸载：¶

  • mount: 挂载文件系统。

  • mmount: 可能是mount命令的变体或脚本，用于挂载文件系统。

  • umount: 卸载文件系统。

文件系统维护：¶

  • mkinitrd: 创建一个初始RAM磁盘。

  • sfdisk: 是一个脚本化的磁盘分区表操作工具。

交换空间管理：¶

  • swapon: 启用交换空间。

  • swapoff: 禁用交换空间。

其他：¶

  • hdparm: 用于硬盘设置和性能调整。

  • symlinks: 可能是用于创建和管理符号链接的命令或脚本。

  • sync: 将所有挂载的文件系统上的修改数据同步到磁盘。

文件系统检查与修复：¶

  • fsck: 是一个用于检查和修复Linux文件系统的命令。

  • fsck.minix: 是一个用于检查和修复Minix文件系统的命令。

  • fsck.ext2: 专门用于检查和修复ext2文件系统的命令。

  • mbadblocks: 可能是badblocks命令的变种。

文件系统创建：¶

  • ext2ed: 是一个用于编辑ext2文件系统超级块和块组描述符的文本模式工具。

  • fdformat: 是一个用于格式化软盘的命令。

  • hdparm: 是一个用于获取和设置硬盘参数的命令。

  • mformat: 是一个用于格式化MS-DOS文件系统的命令。

  • mkbootdisk: 创建一个可启动的磁盘。

  • mkdosfs: 创建MS-DOS文件系统。

  • mke2fs: 创建ext2文件系统。

  • mkfs.ext2: 创建ext2文件系统。

  • mkfs.msdos: 创建MS-DOS文件系统。

  • mkfs: 创建文件系统，具体类型取决于选项。

  • mkfs.minix: 创建Minix文件系统。

  • mkisofs: 创建ISO 9660文件系统，通常用于制作光盘镜像。

  • mkswap: 创建交换空间。

  • mpartition: 是一个磁盘分区工具。

文件系统状态与统计：¶

  • stat: 显示文件或文件系统的详细状态信息。

  • tree: 以树状图的形式显示目录的内容。

4. 网络操作与通信¶

网络与远程访问：¶

  • rlogin: 远程登录到另一个计算机。

  • rsh: 远程执行shell命令。

  • rwho: 显示当前远程登录的用户。

网络配置与管理：¶

  • apachectl: 控制Apache HTTP服务器，用于启动、停止、重启或检查服务器状态。

  • arpwatch: 监控网络接口上的ARP请求，用于跟踪IP地址到MAC地址的映射变化。

  • dip: 一个网络接口配置工具，用于设置或显示网络接口的IP地址。

  • getty: 启动一个终端会话，通常用于登录提示。

  • ifconfig: 配置或显示Linux内核中网络接口的网络参数。

  • mingetty: 一个轻量级的getty，用于启动最小化的终端会话。

  • netconfig: 用于图形化配置网络设置的工具。

  • netstat: 显示网络连接、路由表、接口统计等网络信息。

  • ping: 发送ICMP ECHO请求到指定的主机，用于测试网络连通性。

  • route: 显示或操作内核的IP路由表。

  • traceroute: 显示数据包到目的地的路径，用于诊断网络问题。

网络服务与守护进程：¶

  • httpd: 启动Apache HTTP服务器。

  • smbd: Samba的守护进程，提供文件和打印服务。

  • samba: 可能是指启动或管理Samba服务的命令。

通信与远程访问：¶

  • telnet: 一个网络协议，用于远程登录到计算机。

  • talk: 一个允许用户在网络上进行实时对话的程序。

  • uux: Unix到Unix的拷贝，用于在远程机器上执行命令。

  • wall: 向所有用户发送消息。

串行通信与终端管理：¶

  • minicom: 一个文本模式的调制解调器通信程序。

  • mesg: 允许或拒绝其他用户向您的终端发送消息。

  • setserial: 设置或显示串行端口的参数。

  • statserial: 显示串行端口的状态。

远程文件系统访问：¶

  • rmt: 远程磁带操作，用于备份和恢复。

安全与日志：¶

  • uulog: 显示或操作uucp相关的日志文件。

  • uustat: 显示当前uucp作业的状态。

系统管理：¶

  • ppp-off: 关闭PPP（点对点）连接。

  • pppsetup: 设置或配置PPP连接。

  • pppstats: 显示PPP连接的统计信息。

  • testparm: 检查Samba配置文件的语法。

  • newaliases: 重建或更新邮件别名数据库。

文件传输与打印：¶

  • write: 向另一个终端的用户发送消息。

  • lp: 打印文件或文件集合。

其他：¶

  • cu: 一个命令行的拨号终端。

  • tcpdump: 一个强大的网络抓包工具，用于网络故障排除和数据分析。

  • ytalk: talk程序的改进版本。

  • efax: 一个电子邮件到传真网关。

  • shapecfg: 可能与网络设备的配置有关。

其他相关命令：¶

  • ftpshut: 用于关闭FTP服务。

  • ftpwho: 显示当前连接到FTP服务器的用户。

  • ftpcount: 显示当前连接到FTP服务器的用户数量。

网络配置：¶

  • bind: 可能与网络服务配置相关。

5. 系统启动与关机¶

系统关机操作：¶

  • poweroff: 关闭系统并切断电源。

6. 软件版本控制¶

版本控制与代码管理：¶

  • git: 分布式版本控制系统。

  • gitview: 以图形方式查看Git仓库。

  • gitps: 可能是一个结合了git和ps功能的命令，用于显示与Git仓库相关的进程信息。

7. 脚本编程与自动化¶

脚本编程：¶

  • wc 计算字数，行数和字符数。

  • let 在Shell脚本中执行算术运算。

  • awk: 模式扫描和处理语言，用于文本处理。

  • read: 读取输入的环境变量。

  • cut: 剪切输出的列。

  • diff: 比较文件的差异。

  • diffstat: 显示diff命令的统计信息。

  • file: 确定文件类型。

  • find: 在目录树中搜索文件。

  • grep: 搜索文本模式。

  • indent: 格式化C代码。

  • less: 分页查看文件。

  • more: 分页查看文件，是less的前身。

  • od: 八进制转储。

  • paste: 合并文件的列。

  • patch: 应用或生成补丁文件。

  • split: 将文件分割成多个部分。

  • tee: 将输出分发到多个文件或设备。

  • updatedb: 更新locate数据库。

8. 系统信息与诊断¶

系统信息：¶

  • procinfo: 显示进程信息。

  • uname: 显示系统信息，如内核名称、主机名等。

其他：¶

  • skill: 可能是kill命令的变体，用于发送信号给进程。

  • sliplogin: 为SLIP（串行线路互联网协议）会话提供登录。

  • vlock: 锁定当前的终端会话。

  • logrotate: 管理日志文件的轮换。

  • swatch: 日志文件监控工具。

9. 打印管理¶

打印管理相关命令：¶

  • lprm: 用于删除打印队列中的打印作业。

  • lpr: 用于将文件发送到打印机。

  • lpq: 用于查看打印机队列中的打印作业。

  • lpd: 是打印守护进程，负责管理打印队列和与打印机通信。
