Terminal_Shortcut¶

以下快捷键都是属于 Emacs 模式，Bash 内置了 Readline 库

这个库默认采用 Emacs 快捷键，也可以改成 Vi 快捷键。

$ set -o vi

下面的命令可以改回 Emacs 快捷键。

$ set -o emacs

如果想永久性更改编辑模式（Emacs / Vi），可以将命令写在~/.inputrc文件，这个文件是 Readline 的配置文件。

或者把这跳命令写入.bashrc

set editing-mode vi

Bash 默认开启这个库，但是允许关闭。

下面命令中，–noediting参数关闭了 Readline 库，启动的 Bash 就不带有行操作功能。

$ bash --noediting

Emacs下的快捷键¶

1. 移动¶

快捷键

作用

Ctrl + a/e

跳到行首/行尾

Ctrl + f/b

前/后跳一个字符

Alt + f/b

前/后跳一个词

2. 编辑¶

快捷键

作用

Ctrl + _

Undo

Ctrl + j

Enter

Ctrl + h/d

删除光标前/后一个字符 (也就是向光标后一个一个删除，也就是删除光标所在字符)

Ctrl + w/Alt + d

删除光标前/后一个词

Ctrl + u/k

删除/剪贴到行首/尾

Ctrl + y

粘贴刚才删除的内容

Ctrl + c

终止当前命令/进程

Ctrl + z

暂停当前命令/进程

Ctrl + s

暂停屏幕输出

Ctrl + q

恢复屏幕输出

Alt + .

插入上一条命令的最后一个参数(例如使用ls -la ,下一条命令使用此快捷键后将插入-la)

Alt + u/l

大/小写光标下的字符

Alt + c

大写当前光标下字符并将光标移至词尾

Alt + t

将当前单词与前一个单词位置对调

Ctrl + t

将光标前的字符和光标处的字符进行调换，并且光标后移1位 (可以看作是把光标前一个字符往后面拉)

!$

这个代表上一条命令的最后一个参数，例如ls -la ,下一条命令使用!$,将代表了-la

!^

上一条命令的第一个命令,第一个参数

!*

上一条命令的第一个命令,所有参数

!!

这个命令代表了上一条命令,当要sudo执行的时候会比较方便，sudo !!

!<foo>

执行历史命令里和<foo>开头的命令，例如历史命令里的ls -la,使用!l即可表示之前ls -la 整个命令

![n]

运行历史记录中的第 n 个命令

Ctrl + x + e

使用编辑器编辑当前命令

Vi下的快捷键¶

Vi 模式下分输入模式和命令模式

初始化都是输入模式，只能输入，按下Esc推出输入模式进入命令模式

修改后，再按i或者a进入输入模式

1. 词移动¶

快捷键

描述

w

光标移动到下个单词的开头,不忽略其中的标点符号

W

光标移动到下个单词的开头,忽略词中的标点符号

b

光标移动到上一个单词的开头

B

光标移动到上一个单词的开头,忽略词中的标点符号

e

移动到当前单词和下一个单词的末尾,不跳过标点符号

E

移动到当前单词和下一个单词的末尾,跳过标点符号

f

向后移动光标到查找的字符上

F

向前移动光标到查找的字符上

%

跳转到与其匹配的另一个括号上，可正向匹配临近的一个括号上

2. 修改¶

快捷键

描述

cc

删除此行内容并进入插入模式

cw

修改下个词

C

修改光标处到行末

dw

删除下个词

dd

删除整行

D

删除光标处到行末

x

删除光标处词，向后删除

X

删除光标前词，向前删除

r

替换光标处字符

R

替换从光标处开始到末行所有字符

~

将光标处字符大小写切换

A

光标移到行末，并进入插入模式

y

复制光标处字符

xp

光标处字符和其后一个字符交换位置

yy

复制整行

p

粘贴内容
