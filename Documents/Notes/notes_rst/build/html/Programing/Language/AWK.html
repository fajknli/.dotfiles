AWK 程序设计¶

介绍¶

awk 从它的输入中每次读取一行, 将行分解为一个个的字段 (默认将字段看作是非空白字符组成的序列). 当前输入行的第一个字段叫作 $1, 第二个是 $2, 依次类推. 一整行记为 $0. 每行的字段数有可能不一样. 通常情况下, 我们需要做的是打印每一行的部分或全部字段, 也可能会做一些计算.

1.AWK程序结构¶

awk 'pattern { action }' files

例子：

awk '$3 == 0 { print $1 }' file1 file2

如果某行的第 3 个字段为 0, 那么它的第 1 个字段就会被打印出来 awk 会搜索文件的每一行

awk作用的文件可以是多个文件，例如：

awk '$3 == 0 { print $1 }' file1 file2

  1. 在终端下输入 awk ‘program’,而不输入文件，那么终端就会等待你继续输入文字然后回车确认后就对这文字进行program操作

2. 其中’pattern { action }’ 模式和动作可以单独使用，如果一个动作没有模式, 对于每一个输入行, 该动作都会被执行. 如果只有一个模式没有动作,那么就会输出和这个模式相匹配的行

  1. $0 表示一整行,{ print $0 } ,打印整行

  2. { print $1, $3 }, 引用多个字段，打印多个字段的格式，用逗号

  3. { print NF, $1, $NF } 内建变量NF,存储行字段数量,将会打印每一个输入行的字段数量, 第一个字段, 以及最后一个字段.

  4. { print $1, $2 * $3 },动作里的计算操作

  5. { print NR, $0 } Awk 提供了另一个内建变量 NR, 这个变量计算到目前为止, 读取到的行的数量.

  6. { print “total pay for”, $1, “is”, $2 * $3 } 将文本放入输出中

  7. printf()的使用，{ printf(“total pay for %s is $%.2fn”, $1, $2 * $3) }

Printf()的使用¶

printf() 的格式控制字符串组成如下：

%[flags][width][.precision][length]specifier

%[标志][最小宽度][.精度][长度]说明符，其中[]代表可选的。

标志:

设置字段宽度时设置为左对齐，默认是右对齐(也就是不加”-“)

printf("%-5d,%5d\n",1,2)

输出:

1     ,     2

在数值前面显示正负号。如果没有+号，那么不会在正值前面加上+号

printf("%d,%d,%+d,%+d\n",5,-5,5,-5)

输出:

5,-5,+5,-5

  1. 空格

例如% d,输出就是在数值前面加个空格，没什么特殊

  1. #

与 o、x 或 X 说明符一起使用时，非零值前面会分别显示 0、0x 或 0X。

与e,E和f一起使用时，会强制输出包含一个小数点，
即使后边没有数字时也会显示小数点。默认情况下，如果后边没有数字时候，不会显示显示小数点。

与 g 或 G 一起使用时，结果与使用 e 或 E 时相同，但是尾部的零不会被移除。

  1. 0

在指定填充的数字左边放置零（0）这个是跟宽度参数一块用。

printf("%03d\n",5)

输出:

005

其中3是可选项width的参数，代表三个宽度，如果前面加入0，则代表前面以0填充而不是空格填充。

  1. 数字

要输出的字符的最小长度。如果输出的值的长度短于该数，结果会用空格填充。如果输出的值的长度长于该数，结果不会被截断。

printf("%3d,%3d\n",3,3333)

输出:

"  3,3333"

printf 格式控制字符¶

字符

表达式将被打印成

c

ASCII 字符

d

十进制整数

e

[-]d.ddddddE[+-]dd

f

[-]ddd.dddddd

g

按照 e 或 f 进行转换, 选择较短的那个, 无意义的零会被抑制

o

无符号八进制数

s

字符串

x

无符号十六进制数

%

打印一个百分号 %, 不会有参数被吸收
