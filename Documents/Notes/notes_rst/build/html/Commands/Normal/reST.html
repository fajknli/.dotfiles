1.标题¶

overline, for parts
###################

for sections
============

for subsections
---------------

for paragraphs
""""""""""""""

for subsubsections
^^^^^^^^^^^^^^^^^^

overline, for chapters
**********************

Note

  • # with overline, for parts

  • * with overline, for chapters

  • =, for sections

  • -, for subsections

  • ^, for subsubsections

  • “, for paragraphs

3.有序列表：¶

#. ONE
#. TWO
#. THREE
#. FOUR

  1. ONE

  2. TWO

  3. THREE

  4. Four

Note

  1. ONE .后面必须要有个空格

  2. 如果单行太长了，可以直接换行，但是要保证换行后要有缩进，对齐，不能顶格和序号一起写着。

4.单行修饰：¶

  1. 强调
    ** 我 **:

    我

  2. 斜体（着重）
    * 我 *:

    我

  3. 单行代码块(等宽字体)
    `` 我 ``:

    我

  4. 上标
    E = mc\ :sup:2:

    E = mc2

  5. 下标
    H\ :sub:2\ O:

    H2O

  6. 小提示
    :abbr:提示 (当鼠标在这上面的时候，这里是提示信息):

    提示

  7. 文件地址
    :file:/path/to/file 目录:

    /path/to/file 目录

Note

  1. 字体样式设置后，需要保证前后 各空一字符

    例如：H2O

7.定义¶

htop

互动式进程查看器，用于Linux/Unix系统

传统的进程查看器

htop
    互动式进程查看器，用于Linux/Unix系统
top
    传统的进程查看器

Note

无论两个这样的定义格式之间有多少空格，当它们渲染出来时，都是相邻的。

8.选项列表，参数描述¶

-a

描述:一个-a的选项。

-b file

描述:一个-b的选项，带着file参数。

-a  描述:一个-a的选项。
-b file  描述:一个-b的选项，带着file参数。

Note

1.选项和描述的距离要大于等于两个空格

2.选项和参数的距离要大于等于一个空格

3.如果参数后面有描述，它们的距离也要大于等于两个空格
