3.有序列表：
============

| \#. ONE
| \#. TWO
| \#. THREE
| \#. FOUR


#. ONE
#. TWO
#. THREE
#. Four

.. note::
   #. ONE .后面必须要有个空格
   #. 如果单行太长了，可以直接换行，但是要保证换行后要有缩进，对齐，不能顶格和序号一起写着。

----

4.单行修饰：
============

#. 强调
    :** 我 **: **我**

#. 斜体（着重）
    :* 我 *: *我*
 
#. 单行代码块(等宽字体)
    :`` 我 ``: ``我``
 
#. 上标
    :E = mc\\ \:sup\:`2`: E = mc\ :sup:`2`
 
#. 下标
    :H\\ \:sub\:`2`\\ O: H\ :sub:`2`\ O
 
#. 小提示
    :\:abbr\:`提示 (当鼠标在这上面的时候，这里是提示信息)`: :abbr:`提示 (这里是提示信息)`
 
#. 文件地址
    :\:file\:`/path/to/file` 目录: :file:`/path/to/file` 目录

.. note::
    1. 字体样式设置后，需要保证前后 各空一字符
        例如：H\ :sub:`2`\ O

----

7.定义
=======

htop
    互动式进程查看器，用于Linux/Unix系统
top
    传统的进程查看器

::

    htop
        互动式进程查看器，用于Linux/Unix系统
    top
        传统的进程查看器

.. note::
   无论两个这样的定义格式之间有多少空格，当它们渲染出来时，都是相邻的。

8.选项列表，参数描述
====================

-a  描述:一个-a的选项。
-b file  描述:一个-b的选项，带着file参数。

::
     
    -a  描述:一个-a的选项。
    -b file  描述:一个-b的选项，带着file参数。

.. note::

   1.选项和描述的距离要大于等于两个空格

   2.选项和参数的距离要大于等于一个空格

   3.如果参数后面有描述，它们的距离也要大于等于两个空格

----

--------------

==== ==== ==== ====
A    B    C     D
--------- ---- ----

========= ==== ====
111  222  222  222
111  333  333  333
111  333  333  333
111  333  333  333
==== ==== ==== ====

::

    ==== ==== ==== ====
    A    B    C     D
    --------- ---- ----
    12          3   4
    ========= ==== ====
    111  222  222  222
    111  333  333  333
    111  333  333  333
    111  333  333  333
    ==== ==== ==== ====


复杂类型的表格
--------------

+-----+-----+-----+
|A    |B    |C    |
+=====+=====+=====+
|     |     | 1   |
|1    |   3 |     |
+-----+-----+-----+
|   1 |   2       |
+-----+-----+-----+
|  3  |  2  | 1   |
+-----+-----+-----+


::


    +-----+-----+-----+
    |A    |B    |C    |
    +=====+=====+=====+
    |     |     | 1   |
    |1    |   3 |     |
    +-----+-----+-----+
    |   1 |   2       |
    +-----+-----+-----+
    |  3  |  2  | 1   |
    +-----+-----+-----+

.. note::
   个人更推荐简单的表格，虽然都不怎么方便
