# Python 学习路线

## 阶段一：基础语法

### 1.1 环境搭建
- Python 安装（3.8+）
- IDE/编辑器选择（VS Code、PyCharm）
- 虚拟环境创建（venv）

### 1.2 基础语法
- 变量和数据类型
- 运算符
- 字符串操作
- 控制流（if/else、for、while）
- 函数定义与调用
- 模块和包导入

### 1.3 数据结构
- 列表（list）
- 元组（tuple）
- 字典（dict）
- 集合（set）
- 列表推导式

### 1.4 文件操作
- 读写文件
- 文件模式（r、w、a、b）
- with 语句
- CSV、JSON 处理

## 阶段二：面向对象编程

### 2.1 类和对象
- 类定义
- 构造函数 `__init__`
- 实例属性和类属性
- 实例方法、类方法、静态方法

### 2.2 继承和多态
- 单继承
- 多重继承
- super() 函数
- 方法重写
- MRO 解析顺序

### 2.3 封装
- 私有属性和方法
- property 装饰器
- getter/setter

### 2.4 特殊方法
- `__str__`、`__repr__`
- `__len__`、`__getitem__`
- `__call__`
- 运算符重载

## 阶段三：高级特性

### 3.1 迭代器与生成器
- 迭代器协议
- yield 关键字
- 生成器表达式
- itertools 模块

### 3.2 装饰器
- 函数装饰器
- 类装饰器
- 带参数的装饰器
- functools.wraps

### 3.3 上下文管理器
- with 语句
- `__enter__`/`__exit__`
- contextlib 模块

### 3.4 异常处理
- try/except/else/finally
- 自定义异常
- 异常链

## 阶段四：标准库精要

### 4.1 系统相关
- sys：命令行参数、路径、退出
- os：文件系统、环境变量
- pathlib：面向对象的路径操作

### 4.2 数据处理
- json：JSON 读写
- re：正则表达式
- datetime：日期时间
- random：随机数
- math：数学函数

### 4.3 数据结构
- collections（Counter、defaultdict、deque）
- itertools（chain、cycle、product）

### 4.4 其他
- argparse：命令行参数解析
- logging：日志记录
- unittest：单元测试
- threading：多线程
- multiprocessing：多进程

## 阶段五：第三方库

### 5.1 Web 开发
- Requests：HTTP 请求
- FastAPI/Flask：Web 框架
- BeautifulSoup/Scrapy：网页爬虫

### 5.2 数据处理
- NumPy：数值计算
- Pandas：数据分析
- Matplotlib：数据可视化

### 5.3 图像处理
- Pillow：图像处理
- OpenCV：计算机视觉

### 5.4 其他
- Colorama：终端颜色
- tqdm：进度条
- pytest：测试框架

## 阶段六：项目实战

### 6.1 入门项目
- 计算器
- 待办事项管理
- 天气查询工具
- 文件批量重命名工具

### 6.2 进阶项目
- Web 爬虫
- 博客系统（Flask/Django）
- 数据分析报告
- 自动化脚本

### 6.3 高级项目
- RESTful API 服务
- 桌面应用（Tkinter/PyQt）
- 数据处理管道
- 机器学习模型

| 周次 | 内容 | 时间 |
|------|------|------|
| 第1周 | 基础语法 + 数据结构 | 7天 |

## 一句话总结

Python 学习路径：基础语法 → 数据结构 → 面向对象 → 高级特性 → 标准库 → 第三方库 → 项目实战。每天坚持编码，理论与实践结合。
