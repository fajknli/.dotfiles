# SQL 学习路径

## 阶段一：基础查询

- SELECT 语法
- WHERE 条件筛选
- ORDER BY 排序
- LIMIT 分页
- 子查询

## 阶段二：数据操作

- INSERT 插入数据
- UPDATE 更新数据
- DELETE 删除数据
- 事务控制

## 阶段三：表结构设计

- 数据类型
- CREATE TABLE 创建表
- 约束
- ALTER TABLE 修改表
- DROP 删除
- 索引
- 视图

## 阶段四：函数

- 字符串函数
- 数值函数
- 日期时间函数
- 条件函数
- 类型转换
- 窗口函数

## 阶段五：聚合与分组

- 聚合函数
- GROUP BY 分组
- HAVING 过滤分组
- ROLLUP

## 阶段六：表连接

- INNER JOIN
- LEFT JOIN
- RIGHT JOIN
- FULL JOIN
- CROSS JOIN
- SELF JOIN
- 多表连接

## 阶段七：公用表表达式

- CTE 基础语法
- 多个 CTE
- 递归 CTE
- 实际应用场景

## 阶段八：执行计划与优化

- EXPLAIN 解读
- type 访问类型
- Extra 信息
- 查询优化技巧
- 慢查询分析

## 学习顺序

按以上阶段依次学习，每个阶段完成后做对应练习。
