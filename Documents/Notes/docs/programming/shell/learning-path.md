# Shell 学习路径

## 阶段一：基础语法

- Shebang 和注释
- 变量定义与使用
- 引号（双引号、单引号、反引号）
- 命令替换
- 算术运算
- 退出状态码
- 条件测试（test 和 [ ]）
- 通配符

## 阶段二：控制流

- if 语句
- case 语句
- for 循环
- while 循环
- until 循环
- break 和 continue

## 阶段三：函数

- 函数定义
- 函数参数
- 返回值（退出码 vs 输出）
- 局部变量
- 函数嵌套
- 递归函数
- 函数库

## 阶段四：变量与参数

- 环境变量
- 位置参数（$1, $#, $@, $*）
- shift 移动参数
- 特殊变量（$$, $?, $!）
- 变量替换（默认值、字符串删除、字符串替换）
- 命令替换

## 阶段五：重定向与管道

- 标准输入输出
- 输出重定向（覆盖、追加）
- 输入重定向
- Here Document
- 管道
- tee 命令
- 自定义文件描述符

## 阶段六：文本处理

- grep（搜索、正则表达式）
- sed（替换、删除、打印）
- awk（列处理、计算、格式化）
- cut（列提取）
- sort（排序）
- uniq（去重统计）
- wc（统计）
- tr（字符转换）

## 阶段七：调试与最佳实践

- 语法检查（sh -n）
- 调试模式（sh -x）
- 严格模式（set -eu）
- 错误处理
- 信号捕获（trap）
- 临时文件（mktemp）
- 安全使用变量
- 可移植性（POSIX）
- 常见陷阱

## 学习顺序

按以上阶段依次学习，每个阶段完成后做对应练习。

## 练习建议

| 阶段 | 练习 |
|------|------|
| 基础 | 编写简单计算器脚本 |
| 控制流 | 编写交互式菜单脚本 |
| 函数 | 创建通用函数库 |
| 参数 | 编写带命令行参数的脚本 |
| 重定向 | 编写日志记录脚本 |
| 文本处理 | 编写日志分析脚本 |
| 调试 | 使用 shellcheck 检查脚本 |
