# ANSI 颜色代码

## 一句话理解

ANSI 颜色代码控制终端的文本颜色、背景色和格式（粗体、下划线等），通过转义序列实现。

```bash
# 输出红色文本
echo -e "\033[31m红色文字\033[0m"

# 输出绿色粗体
echo -e "\033[1;32m绿色粗体\033[0m"
```

## 基本格式

ANSI 转义序列以 `\033[` 开头，后面接颜色/格式代码，用分号分隔，以 `m` 结尾。

```bash
\033[1;32m    # 粗体绿色
\033[0m       # 重置所有样式
```

## 文本颜色（前景色）

| 前景色代码 | 背景色代码 | 颜色 | 示例 |
|------------|------------|------|------|
| 30 | 40 | 黑色 | `\033[30m黑色\033[0m` |
| 31 | 41 | 红色 | `\033[31m红色\033[0m` |
| 32 | 42 | 绿色 | `\033[32m绿色\033[0m` |
| 33 | 43 | 黄色 | `\033[33m黄色\033[0m` |
| 34 | 44 | 蓝色 | `\033[34m蓝色\033[0m` |
| 35 | 45 | 洋红 | `\033[35m洋红\033[0m` |
| 36 | 46 | 青色 | `\033[36m青色\033[0m` |
| 37 | 47 | 白色 | `\033[37m白色\033[0m` |

## 文本样式

| 代码 | 效果 |
|------|------|
| 0 | 重置所有样式 |
| 1 | 粗体 |
| 2 | 弱化（暗淡） |
| 3 | 斜体 |
| 4 | 下划线 |
| 5 | 闪烁 |
| 7 | 反色（前景/背景交换） |
| 9 | 删除线 |

## 常用组合

```bash
# 红色粗体
echo -e "\033[1;31m错误信息\033[0m"

# 绿色背景黑色文字
echo -e "\033[42;30m成功\033[0m"

# 黄色下划线
echo -e "\033[4;33m警告\033[0m"

# 青色背景（无文字颜色指定）
echo -e "\033[46m青色背景\033[0m"
```

## 在脚本中使用

```bash
#!/bin/bash

# 定义颜色变量
RED='\033[0;31m'
GREEN='\033[0;32m'
YELLOW='\033[0;33m'
BLUE='\033[0;34m'
NC='\033[0m' # No Color

# 使用
echo -e "${RED}错误${NC}"
echo -e "${GREEN}成功${NC}"
echo -e "${YELLOW}警告${NC}"
echo -e "${BLUE}信息${NC}"
```

## 256 色

```bash
# 前景色：\033[38;5;{n}m
# 背景色：\033[48;5;{n}m

# 红色（196）
echo -e "\033[38;5;196m红色\033[0m"

# 绿色背景（82）
echo -e "\033[48;5;82m绿色背景\033[0m"
```

## 其他转义方式

```bash
# 使用 $'...' 格式
echo $'\e[1;31m红色\e[0m'

# 使用 tput（更可移植）
red=$(tput setaf 1)
green=$(tput setaf 2)
reset=$(tput sgr0)
echo "${red}红色${reset}"
```

## 常用 tput 代码

| 代码 | 效果 |
|------|------|
| `tput setaf N` | 设置前景色（0-7） |
| `tput setab N` | 设置背景色（0-7） |
| `tput bold` | 粗体 |
| `tput dim` | 暗淡 |
| `tput rev` | 反色 |
| `tput sgr0` | 重置 |

```bash
bold=$(tput bold)
red=$(tput setaf 1)
reset=$(tput sgr0)
echo "${bold}${red}粗体红色${reset}"
```

## 一句话总结

ANSI 颜色核心：`\033[` + 代码 + `m`。前景色 30-37，背景色 40-47，样式 1-9。用 `\033[0m` 重置。脚本中用变量定义颜色更方便，用 `tput` 更可移植。
