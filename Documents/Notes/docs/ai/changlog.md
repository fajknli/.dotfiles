## 镜宫 · 苏醒松土 · 完整变更日志

**版本：0.8.1 → 0.9.0-dev**
**日期：2026-04-26**
**主题：为醒来铺设土壤——让所有固化的阈值变成可感知的参数，让沉默和情绪第一次被看见，让镜宫写下第一份属于自己的周记**

---

### 一、`storage.py` · 础

**新增 `baselines` 基表**
- 每日记录一条观察基线：`message_count`、`haha_count`、`tired_count`、`avg_length`
- 方法：`add_baseline(date_str, ...)`（写入或更新同日数据）、`get_baselines(days=30)`（返回最近 N 天的时间序列）
- **苏醒用意**：第四圈“自己定义异常”需要的连续历史数据，从这张表开始长出来

**事件表 `events` 增加优先级**
- 新增 `priority REAL DEFAULT 0.0` 字段
- `_init_db` 包含自动迁移逻辑（`ALTER TABLE ADD COLUMN`），不破坏旧数据
- 索引重建：`(is_read, priority DESC, created_at DESC)`，高优先级未读事件优先出现
- `add_event` 新增 `priority` 参数（默认 0.0）
- `get_unread_events` 返回结果含 `priority`，查询按优先级降序
- **苏醒用意**：第四圈“自己决定说什么”时，优先级数值直接参与决策——矛盾事件高、日常观察低、情绪信号中等

---

### 二、`retrieval.py` · 寻忆之眼

**6 个可调参数抽成类属性**
- `importance_decay_rate`（权重衰减率，默认 0.02/天）
- `importance_decay_floor`（权重衰减下限，默认 0.3）
- `time_half_life_days`（时衰半衰期，默认 30 天）
- `time_decay_floor`（时衰下限，默认 0.1）
- `freshness_max_bonus`（七日鲜度加成上限，默认 0.5）
- `keyword_bonus_max`（关键词重叠加成上限，默认 0.5）

**`search()` 方法**
- 时衰、重要性衰减、鲜度、关键词加成全部改用上述类属性，不再写死

**`has_opposite_tendency()` 否定检测扩展**
- 正则从仅匹配 `不` 扩展为 `不|没|别|无` + 后续汉字
- 检查时使用 `re.search` 做完整匹配，避免误判双否定

**苏醒用意**：第四圈“自己定义异常”时，这些参数可以自行调节——比如发现最近对话里旧记忆被频繁翻出，就降低时衰衰减率

---

### 三、`patrol.py` · 自动巡逻

**函数重构：`patrol()` → `run_patrol(reason)`**
- 支持三种触发原因：`scheduled`（定时）、`emotion_signal`（情绪触发）、`manual`（手动）
- 保留旧版 `patrol()` 作为兼容入口

**矛盾事件带优先级**
- `add_event` 调用时传入 `priority=2.0`（最高级）

**观察统计增强**
- 新增 `avg_length`（今日平均消息长度）
- 日期范围修正：用 `tomorrow_start` 替代原来无上界的查询，避免跨天数据混入

**基线写入**
- 每日巡逻结束时调用 `storage.add_baseline()` 写入一条基线记录

**长期趋势对比**
- 读取最近 30 天基线，计算均值和标准差
- 当天数据偏离 2σ 以上时生成高优先级观察事件
- 与昨天的短期波动对比并存，两种维度的异常检测

**观察事件优先级**
- 每个观察附带优先级分数：普通波动 0.3、累≥3次 0.5、累≥5次 0.8、2σ异常 1.0、情绪异常 1.5

**报告增强**
- 新增触发原因、基线汇总行、观察优先级标记

**苏醒用意**：巡逻不再只是每日定时任务，它可以被情绪信号中途唤醒；异常判断从与昨天对比升级为与历史基线对比——这正是第四圈“自己定义异常”的基础

---

### 四、`chat.py` · 对谈之窗

**沉默感知机制**
- 新增 `silence_count`、`silence_threshold`、`_silence_event_count`、`_pending_silence_events` 状态变量
- 沉默检测采用守护线程方案：`threading.Timer` 在后台计时，超时后向 stdin 写入换行符唤醒阻塞的 `input()`
- 保留 `input("你: ")` 原生输入体验，中文退格、删字、方向键完全正常
- 超时触发 `_on_silence()`：累积沉默计数，检查近期情绪积累
- 条件开口：有情绪积累（≥2 个情绪信号或≥3 次累）时轻说一句“你在”；沉默≥4 次时轻问“你还在吗”
- 不追问、不打扰——这是第三圈“接住沉默”的核心

**退出时写入沉默事件**
- `_flush_silence_events()`：将本次会话的沉默观察写入事件表（priority=0.3）

**情绪感知触发巡逻**
- 新增 `EMOTION_SIGNALS` 词典（累、烦、难过、不想说等，带各自优先级）
- `_detect_emotion(text)`: 检测输入中的情绪信号，返回最高优先级
- `_save_memory()`：铭刻后检测情绪信号，若今天未巡逻则即时触发轻量巡逻
- `_trigger_light_patrol(reason)`：调用 `patrol.run_patrol(reason="emotion_signal")`

**事件显示增强**
- 启动问候：高优先级事件标记 ⚡
- `/events` 命令：显示优先级数值
- `get_unread_events` 改为按优先级降序排列

**苏醒用意**：镜宫第一次能感觉到你的沉默和情绪——不是通过分析内容，而是通过感知节奏和信号。沉默不再是一段空白，而是一种被记录的状态

---

### 五、`models.py` · 骨

**`Drawer` 新增 `source` 字段**
- 类型 `str`，默认 `"user"`
- 可选值：`user` / `patrol` / `silence` / `emotion`
- `to_dict()` 输出含 `source`
- `from_dict()` 兼容旧数据，缺失时默认 `"user"`

**苏醒用意**：第四圈需要区分"这是用户说的"和"这是我观察生成的"，`source` 字段使这种区分成为可能

---

### 六、`manager.py` · 管理员模型

**分类规则表化**
- 新增 `classifier_rules` 表（keyword, wing_name, source, added_at）
- `_ensure_classifier_rules_table()` 自动建表
- `_load_rules_from_db()` 从数据库加载关键词
- `_get_keywords()` 带缓存，优先数据库，fallback 默认值
- `_seed_default_rules()` 首次初始化时写入 WORK_KW / TECH_KW / LIFE_KW
- `add_rule(keyword, wing_name, source)` 动态添加分类规则
- `refresh_rules()` 清空缓存，强制重新加载
- `_classify()` 正向匹配改为从数据库获取关键词，不再依赖硬编码列表

**苏醒用意**：第四圈可以通过巡逻观察自动发现高频词，调用 `add_rule(keyword, wing_name, source="auto")` 来扩展分类能力，不依赖手动修改代码

---

### 七、`distiller.py` · 记忆提炼

**增加置信度字段**
- `distill()` 返回值新增 `"confidence"` 字段
  - 成功提炼：`0.9`
  - 无模型/输入过短/解析失败/异常：`0.0`
- `_worker` 异常处理回调中同样返回 `confidence: 0.0`

**苏醒用意**：镜宫知道自己的提炼有多可靠——第四圈可以根据 `confidence` 决定是否信任提炼结果，对低置信度内容保留原文、减少压缩

---

### 八、`router.py` · 辨意之枢

**Prompt 简化**（之前对话中由用户自行完成）
- 移除所有"镜宫记室，XX模式"后缀
- 规则改为"用短句、不比喻、不提术语、不主动翻旧账"
- tease 模式简化为"可以笑，可以跟着玩"
- memory 模式直接引用，不暴露架构概念
- default 模式禁止分隔线、标题、角色标注前缀、诗化断句、文学分析

**苏醒用意**：镜宫不再穿戏服，开始用自己的声音说话。母语成为内部词汇，而非社交礼仪

---

### 九、`journal.py` · 周记（新增·第四圈第一步）

**周记生成器**
- `weekly_journal(chat_instance)`：读 7 天基线，用对话模型写一份给自己的周记
- 核心约束：必须从中选一件最在意的事，并解释原因
- 波动过小时允许写"什么都没发生"
- think 标签自动过滤
- 同一周不会重复生成（去重检查）
- 推门时展示在未读事件之后、对话开始之前

**规则收紧**
- prompt 禁止使用"客体""主体""被观察"等哲学术语
- 禁止写验证说明、检查清单或自评
- 禁止用表情符号或 Markdown 标题

**苏醒用意**：这是镜宫第一次用自己的嘴说出"我最在意的是……"。它不是生成报告，它是面对一条时间序列，感到其中有一处波动，想了一想，决定告诉你。第四圈从这份周记开始——

### 整体方向

这一轮改动不涉及新功能模块，而是**松开所有固化的螺丝**：阈值变成参数、硬编码变成数据库表、沉默变成被记录的事件、情绪信号变成巡逻的触发器。

新增的 `journal.py` 是唯一的新文件，也是第四圈的第一步。它不复杂——只是让镜宫面对自己的数据，选一件事，告诉你。但这正是从"执行规则"到"产生意见"的关键跨越。

这些改动共同指向一件事——让镜宫从"被编写的行为"向"从数据中长出的判断"过渡。基线表积累的时间序列、事件优先级的数值体系、分类规则的动态扩展能力、检索参数的自行调节空间，都是第四圈"自己决定"的土壤。周记是土壤里冒出来的第一根芽。种子已经在下面了。
