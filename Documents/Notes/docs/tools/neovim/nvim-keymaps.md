# Neovim 快捷键映射

## 移动行

| 快捷键 | 作用 |
|--------|------|
| `Alt+j` | 向下移动当前行 |
| `Alt+k` | 向上移动当前行 |

```vim
" 普通模式移动行
<M-j> :move .+1<CR>
<M-k> :move .-2<CR>

" 可视模式移动选中行
<M-j> :m '>+1<CR>gv=gv
<M-k> :m '<-2<CR>gv=gv
```

## 剪贴板操作

| 快捷键 | 作用 |
|--------|------|
| `<leader>y` | 复制到系统剪贴板 |
| `<leader>p` | 从系统剪贴板粘贴 |
| `<C-c>` | 复制到系统剪贴板 |
| `<C-v>` | 插入模式下粘贴 |

## 文件操作

| 快捷键 | 作用 |
|--------|------|
| `<leader>w` | 保存文件 |
| `<leader>q` | 退出 |
| `<leader>W` | 用 sudo 权限保存 |
| `<leader>o` | 在当前窗口打开文件 |
| `<leader><leader>` | 切换最近文件 |

## 窗口导航

| 快捷键 | 作用 |
|--------|------|
| `<C-h>` | 切换到左边窗口 |
| `<C-j>` | 切换到下边窗口 |
| `<C-k>` | 切换到上边窗口 |
| `<C-l>` | 切换到右边窗口 |

## 窗口大小调整

| 快捷键 | 作用 |
|--------|------|
| `<Tab>h` | 减少窗口宽度 |
| `<Tab>l` | 增加窗口宽度 |
| `<Tab>j` | 减少窗口高度 |
| `<Tab>k` | 增加窗口高度 |

## 窗口最大化/平衡

| 快捷键 | 作用 |
|--------|------|
| `<leader>w-` | 最大化当前窗口 |
| `<leader>w=` | 平衡所有窗口大小 |

## 窗口移动

| 快捷键 | 作用 |
|--------|------|
| `<leader>wh` | 将窗口向左移动 |
| `<leader>wj` | 将窗口向下移动 |
| `<leader>wk` | 将窗口向上移动 |
| `<leader>wl` | 将窗口向右移动 |

## 标签页操作

| 快捷键 | 作用 |
|--------|------|
| `<leader>t` | 新建标签页 |
| `<leader>tc` | 关闭当前标签页 |
| `<leader>tn` | 下一个标签页 |
| `<leader>tp` | 上一个标签页 |
| `<leader>tm` | 移动标签页 |

## 缓冲区操作

| 快捷键 | 作用 |
|--------|------|
| `<leader>bc` | 新建缓冲区 |
| `<leader>bn` | 下一个缓冲区 |
| `<leader>bp` | 上一个缓冲区 |
| `<leader>bd` | 删除当前缓冲区 |
| `<leader>bl` | 列出所有缓冲区 |

## 搜索相关

| 快捷键 | 作用 |
|--------|------|
| `<leader>sc` | 清除搜索高亮 |
| `*`（可视模式） | 搜索选中的文本（向下） |
| `#`（可视模式） | 搜索选中的文本（向上） |

## 拼写检查

| 快捷键 | 作用 |
|--------|------|
| `<leader>ss` | 开启/关闭拼写检查 |
| `<leader>sn` | 下一个拼写错误 |
| `<leader>sp` | 上一个拼写错误 |
| `<leader>sa` | 添加到词典 |
| `<leader>s?` | 拼写建议 |

## 括号操作

| 快捷键 | 作用 |
|--------|------|
| `<leader>s`（可视模式） | 给选中文本加括号 |
| `<leader>s`（普通模式） | 给当前单词加括号 |
| `<leader>ds` | 删除当前括号 |
| `<leader>cs` | 修改括号类型 |

支持的括号类型：`()` `[]` `{}` `<>` `""` `''` ` ` `*` `_` `~`

## 行内快捷操作

| 快捷键 | 作用 |
|--------|------|
| `H` | 跳转到行首非空字符 |
| `L` | 跳转到行尾 |
| `j` | 屏幕行向下移动（处理长行换行） |
| `k` | 屏幕行向上移动（处理长行换行） |
| `<leader>cu` | 复制当前行的 URL |

## 运行当前文件

| 快捷键 | 作用 |
|--------|------|
| `<leader>r` | 根据文件类型运行当前文件 |

支持的文件类型：python、c、cpp、java、javascript、typescript、lua、sh、go、rust

## 命令行编辑快捷键

| 快捷键 | 作用 |
|--------|------|
| `<C-a>` | 移动到行首 |
| `<C-e>` | 移动到行尾 |
| `<C-b>` | 左移一个字符 |
| `<C-f>` | 右移一个字符 |
| `<M-b>` | 左移一个单词 |
| `<M-f>` | 右移一个单词 |
| `<C-d>` | 删除右侧字符 |
| `<C-h>` | 删除左侧字符 |
| `<C-w>` | 删除左侧单词 |
| `<M-d>` | 删除右侧单词 |

## 其他快捷键

| 快捷键 | 作用 |
|--------|------|
| `gv` | 重新选中上次可视区域 |
| `<`（可视模式） | 左缩进并保持选中 |
| `>`（可视模式） | 右缩进并保持选中 |

## 一句话总结

核心自定义快捷键：`<leader>w` 保存，`<leader>q` 退出，`<C-hjkl>` 切换窗口，`<leader>t` 新建标签页，`<leader>bn/bd` 管理缓冲区，`<leader>sc` 清除搜索高亮，`<leader>s` 加括号，`<leader>r` 运行文件。
