# Vim / Neovim 快捷键速查

## 模式切换

| 命令 | 说明 |
|------|------|
| `Esc` | 返回普通模式 |
| `i` | 光标前插入 |
| `a` | 光标后插入 |
| `I` | 行首插入 |
| `A` | 行尾插入 |
| `o` | 下方新行插入 |
| `O` | 上方新行插入 |
| `v` | 可视模式（字符） |
| `V` | 可视行模式 |
| `Ctrl+v` | 可视块模式 |
| `R` | 替换模式 |

## 查找与替换

### 查找

| 命令 | 说明 |
|------|------|
| `/pattern` | 向下查找 |
| `?pattern` | 向上查找 |
| `n` | 下一个匹配 |
| `N` | 上一个匹配 |
| `*` | 查找光标下单词（向下） |
| `#` | 查找光标下单词（向上） |
| `:noh` | 取消高亮 |

### 替换

| 命令 | 说明 |
|------|------|
| `:s/old/new` | 替换当前行第一个 |
| `:s/old/new/g` | 替换当前行所有 |
| `:%s/old/new/g` | 替换全文所有 |
| `:%s/old/new/gc` | 替换全文，逐个确认 |
| `:n,ms/old/new/g` | 替换 n 到 m 行 |

### 实用命令

| 命令 | 说明 |
|------|------|
| `:g/^\(.*\)$\n\1$/p` | 查找重复行（高亮，不修改） |
| `:sort u` | 排序并去重 |
| `:%s/word1/word2/` | 替换单词 |

## 文本对象

| 命令 | 说明 |
|------|------|
| `aw` | 一个单词（含空格） |
| `iw` | 单词内部 |
| `as` | 一个句子（含空格） |
| `is` | 句子内部 |
| `ap` | 一个段落（含空行） |
| `ip` | 段落内部 |
| `a"` / `i"` | 双引号内 |
| `a'` / `i'` | 单引号内 |

| `a{` / `i{` | 花括号内 |

示例：`ciw` 修改当前单词，`da"` 删除双引号及内容，`yip` 复制段落。

## 常用配置示例

```vim
" 设置 leader 键为空格
let mapleader = " "

" 停止高亮
map <silent> <leader><cr> :noh<cr>

" 打开/关闭粘贴模式
map <leader>pp :setlocal paste!<cr>

" 保存文件
map <leader>w :w<cr>

" 退出
map <leader>q :q<cr>

" 重新加载配置
map <leader>so :so %<cr>

" 窗口快捷键
noremap <leader>hh :sp<cr>
noremap <leader>vv :vsp<cr>
noremap <C-h> <C-w>h
noremap <C-j> <C-w>j
noremap <C-k> <C-w>k
noremap <C-l> <C-w>l

" 标签页快捷键
noremap <leader>tn :tabnew<cr>
noremap <leader>tc :tabc<cr>
noremap <leader>to :tabo<cr>
noremap <leader>th gT
noremap <leader>tl gt

" 缓冲区快捷键
noremap <leader>bn :bn<cr>
noremap <leader>bp :bp<cr>
noremap <leader>bd :bd<cr>
```

## 一句话总结

Vim 核心：`i` 进入插入，`Esc` 退出，`dd` 删行，`yy` 复制，`p` 粘贴，`/` 搜索，`:%s/old/new/g` 替换，`:w` 保存，`:q` 退出。多用 `.` 重复操作，用 `qa` 录制宏。长行用 `gj`/`gk` 移动，数字用 `Ctrl+a`/`Ctrl+x` 增减，查找重复行用 `:g/^\(.*\)$\n\1$/p`。
