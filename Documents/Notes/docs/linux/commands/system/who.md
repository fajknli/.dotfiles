# who - 显示登录用户信息

## 一句话理解

who 命令显示当前登录系统的用户列表，比 w 更简洁。

```bash
# 查看当前登录用户
who

# 输出示例：
# fajknli  tty2         2026-04-09 09:00 (:0)
# fajknli  pts/0        2026-04-09 10:00 (192.168.1.100)
```

## 常用场景

### 1. 查看当前登录用户

```bash
# 基本查看
who

# 只显示用户名
who | awk '{print $1}'

# 统计登录用户数
who | wc -l
```

### 2. 查看用户数量和汇总

```bash
# 显示用户名和数量
who -q

# 输出示例：
# fajknli fajknli root
# # users=3
```

### 3. 查看系统启动时间

```bash
# 查看系统上次启动时间
who -b

# 输出示例：
# system boot  2026-04-07 08:30
```

### 4. 查看运行级别

```bash
# 查看当前运行级别
who -r

# 输出示例：
# run-level 5 2026-04-07 08:30
```

### 5. 查看登录历史

```bash
# 查看所有登录历史（需要 utmp 文件）
who /var/log/wtmp

# 查看登录失败历史
who /var/log/btmp
```

## 常用选项速查

| 选项 | 说明 | 例子 |
|------|------|------|
| `-b` | 系统上次启动时间 | `who -b` |
| `-q` | 显示用户名和数量 | `who -q` |
| `-r` | 当前运行级别 | `who -r` |
| `-d` | 僵尸进程 | `who -d` |
| `-H` | 显示标题行 | `who -H` |
| `-l` | 登录进程 | `who -l` |
| `-m` | 只显示当前终端 | `who -m` |
| `-u` | 显示空闲时间 | `who -u` |

## 输出字段说明

| 字段 | 说明 |
|------|------|
| USER | 用户名 |
| LINE | 终端（tty=本地，pts=远程） |
| TIME | 登录时间 |
| COMMENT | 来源（本地显示 (:0)，远程显示 IP） |

## 常见问题

### 1. who 和 w 有什么区别？

| 命令 | 特点 |
|------|------|
| `who` | 简洁，只显示用户和登录信息 |
| `w` | 详细，还显示用户活动和 CPU 使用 |
| `who -q` | 只显示用户名和数量 |

### 2. 如何查看历史登录记录？

```bash
# 查看最近登录
last

# 查看指定用户的登录历史
last fajknli

# 查看失败登录
lastb
```

### 3. 如何查看当前用户是谁？

```bash
# 查看当前用户名
whoami

# 或
id -un

# 查看当前用户的详细信息
who -m
```

## 快捷别名

```bash
alias who-simple='who -q'
alias who-boot='who -b'
alias who-runlevel='who -r'
alias who-header='who -H'
```

## 一句话总结

who 核心：`who` 查看当前登录用户，`who -q` 显示用户数量和列表，`who -b` 查看系统启动时间，`who -r` 查看运行级别。查历史用 `last`，查失败登录用 `lastb`。比 `w` 更简洁。
