# top - 实时系统监控工具

## 一句话理解

top 是 Linux 实时任务管理器，显示 CPU、内存、进程等信息，类似任务管理器。

```bash
top                    # 启动 top
htop                   # 更友好的版本（推荐）
btop                   # 更美观的版本
```

## 界面说明

### 第一行：系统负载

```
top - 10:30:45 up 2 days, 5:32, 3 users, load average: 0.08, 0.03, 0.01
```

| 字段 | 说明 |
|------|------|
| `10:30:45` | 当前时间 |
| `up 2 days` | 系统已运行时间 |
| `3 users` | 登录用户数 |
| `load average` | 1/5/15 分钟平均负载 |

### 第二行：进程统计

```
Tasks: 150 total, 1 running, 149 sleeping, 0 stopped, 0 zombie
```

| 字段 | 说明 |
|------|------|
| `total` | 总进程数 |
| `running` | 运行中进程 |
| `sleeping` | 睡眠进程 |
| `stopped` | 停止进程 |
| `zombie` | 僵尸进程 |

### 第三行：CPU 使用率

```
%Cpu(s): 5.2 us, 2.1 sy, 0.0 ni, 92.0 id, 0.5 wa, 0.1 hi, 0.1 si, 0.0 st
```

| 字段 | 说明 |
|------|------|
| `us` | 用户空间占用 |
| `sy` | 内核空间占用 |
| `ni` | 优先级调整进程占用 |
| `id` | 空闲 CPU |
| `wa` | 等待 I/O 完成 |
| `hi` | 硬中断处理 |
| `si` | 软中断处理 |
| `st` | 被虚拟机偷走的 CPU |

### 第四行：内存使用

```
MiB Mem : 15985.0 total, 2345.6 free, 8234.5 used, 5404.9 buff/cache
```

### 第五行：交换分区

```
MiB Swap: 8192.0 total, 7123.4 free, 1068.6 used, 6543.2 avail Mem
```

### 进程列表

| 列 | 说明 |
|----|------|
| `PID` | 进程 ID |
| `USER` | 运行用户 |
| `PR` | 优先级 |
| `NI` | nice 值 |
| `VIRT` | 虚拟内存 (KB) |
| `RES` | 常驻物理内存 (KB) |
| `SHR` | 共享内存 (KB) |
| `S` | 状态 (R=运行, S=睡眠, D=不可中断, Z=僵尸, T=停止) |
| `%CPU` | CPU 使用率 |
| `%MEM` | 内存使用率 |
| `TIME+` | 累计 CPU 时间 |
| `COMMAND` | 命令名 |

## 常用交互命令

### 排序

| 按键 | 作用 |
|------|------|
| `P` | 按 CPU 使用率排序（默认） |
| `M` | 按内存使用率排序 |
| `T` | 按累计 CPU 时间排序 |
| `N` | 按 PID 排序 |
| `R` | 反向排序 |

### 显示控制

| 按键 | 作用 |
|------|------|
| `1` | 展开/合并多核 CPU 显示 |
| `t` | 切换 CPU 行显示模式 |
| `m` | 切换内存行显示模式 |
| `c` | 显示完整命令行 |
| `V` | 树形显示进程关系 |
| `H` | 显示线程（而非进程） |

### 过滤和查找

| 按键 | 作用 |
|------|------|
| `u` | 只显示指定用户的进程 |
| `O` | 按条件过滤（如 `%MEM>10`） |
| `L` | 查找字符串 |
| `&` | 查找并高亮 |

### 操作进程

| 按键 | 作用 |
|------|------|
| `k` | 终止进程（输入 PID 和信号） |
| `r` | 调整进程优先级（renice） |
| `d` | 设置刷新间隔（秒） |
| `W` | 保存当前配置到 ~/.toprc |

### 退出

| 按键 | 作用 |
|------|------|
| `q` | 退出 top |
| `h` | 显示帮助 |

## 命令行参数

```bash
# 指定刷新间隔（秒）
top -d 2

# 指定刷新次数后退出
top -n 5

# 只监控指定 PID
top -p 1234
top -p 1234,5678,9012

# 只监控指定用户
top -u username

# 批处理模式（输出到文件）
top -b -n 1 > top.txt

# 安全模式（禁用交互命令）
top -s

# 累计模式（显示进程总 CPU 时间）
top -S
```

## 实际例子

### 查找高 CPU 进程

```bash
# 启动 top，按 P 键（CPU 排序）
# 观察顶部进程，记下 PID

# 或一次性查看
top -b -n 1 | head -20
```

### 查找高内存进程

```bash
# 启动 top，按 M 键（内存排序）
```

### 监控特定进程

```bash
# 获取进程 PID
pgrep firefox

# 监控该进程
top -p $(pgrep -d, firefox)
```

### 记录系统状态

```bash
# 每 5 秒记录一次，共 12 次，输出到文件
top -b -d 5 -n 12 > top.log
```

### 检查僵尸进程

```bash
# 观察第二行 Tasks，zombie 数量
# 若不为 0，查找僵尸进程
ps aux | awk '$8=="Z"'
```

## 替代工具

### htop（推荐）

```bash
sudo pacman -S htop
htop
```

优势：
- 彩色界面，更直观
- 支持鼠标操作
- 可以垂直/水平滚动
- 按 F2 配置显示列

### btop（更美观）

```bash
sudo pacman -S btop
btop
```

优势：
- 图形化界面
- 显示网络、磁盘等更多信息
- 现代化 UI

### atop

```bash
sudo pacman -S atop
atop
```

优势：
- 记录历史数据
- 显示更多系统资源（磁盘、网络）

## 配置保存

```bash
# 在 top 中按 W 键，保存配置到 ~/.toprc

# ~/.toprc 示例
# RCfile for top
Idle 0
Cpu_aid 1
RCmode 1
```

## 常见问题

### 1. load average 含义

```bash
# 单核 CPU，load average 应 < 1.0
# 4 核 CPU，load average 应 < 4.0
# 超过核心数说明系统繁忙
```

### 2. wa（iowait）过高

```bash
# 磁盘 I/O 瓶颈
# 使用 iostat 查看磁盘
iostat -x 1
```

### 3. 僵尸进程

```bash
# 找到僵尸进程的父进程
ps -o ppid= -p <ZOMBIE_PID>

# 重启父进程或 kill -HUP 父进程
sudo kill -HUP <PPID>
```

## 一句话总结

top 核心：`P` 按 CPU 排序，`M` 按内存排序，`1` 看多核，`c` 看完整命令，`k` 终止进程，`u` 过滤用户，`q` 退出。日常用 `htop` 更友好，问题排查用 `top -b -n 1` 一次性输出。
